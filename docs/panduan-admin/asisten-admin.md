# Asisten Admin

Kata kunci: asisten, tanya, chat admin, bisa apa, suara, mikrofon

Asisten Admin menjawab pertanyaan data dari fungsi laporan dan stok yang sama dengan halaman admin, sesuai izinmu. Contoh: "Omzet minggu ini dibanding minggu lalu", "Stok cushion shade 02 di sini", "Saran transfer hari ini", "Cara membuat voucher".

- Jawaban selalu menyebut periode dan sumber angkanya, lengkap dengan tautan ke halaman terkait.
- Bila nama yang kamu sebut cocok dengan beberapa produk atau cabang, asisten bertanya balik.
- Asisten hanya membaca. Untuk aksi seperti transfer atau flash sale, ia membuka draf di formulir yang ada; kamu yang menyimpan. Membatalkan pesanan, mengubah harga, dan menghapus data tidak bisa lewat asisten.
- Tombol mikrofon merekam maksimal 60 detik, lalu teksnya masuk ke kotak ketik untuk kamu periksa. Rekaman tidak disimpan dan tidak terkirim otomatis.
