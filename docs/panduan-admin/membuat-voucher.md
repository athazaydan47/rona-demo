# Membuat voucher

Kata kunci: voucher, kode promo, diskon, potongan, gratis ongkir

Butuh izin: Kelola promo dan voucher.

1. Buka menu Promo, lalu tab Voucher.
2. Tekan "Buat voucher".
3. Isi kode (huruf besar dan angka saja), judul, dan tipe: nominal (potongan rupiah), persen (isi juga potongan maksimal), atau ongkir (gratis ongkir).
4. Isi minimal belanja, waktu mulai dan selesai (WIB), kuota total, dan kuota per pembeli.
5. Simpan. Voucher langsung bisa dipakai di checkout selama masa berlakunya.

Catatan: kode voucher yang sudah pernah dipakai tidak bisa diubah. Untuk menghentikan voucher, matikan saja, jangan dihapus, supaya laporan tetap utuh.
