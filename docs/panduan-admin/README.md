# Panduan admin Rona Beauty

Panduan singkat per tugas di panel admin. Dibaca tool `panduan_admin` milik Asisten Admin, jadi jawaban "cara pakai" selalu berasal dari teks di sini, bukan karangan AI. Setiap berkas diawali judul, lalu baris "Kata kunci" untuk pencocokan topik. Tulis langkah dengan bahasa singkat dan sapaan "kamu".
