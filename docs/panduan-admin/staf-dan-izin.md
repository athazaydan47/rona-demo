# Staf dan izin

Kata kunci: staf, akun, izin, peran, owner, gudang, cabang

Butuh izin: Kelola akun staf dan izin.

1. Buka menu Staf dan izin, tekan "Tambah staf".
2. Pilih peran: Owner, Admin Online, Staf Cabang (wajib pilih cabang), atau Gudang. Izin awal mengikuti peran.
3. Tambah atau cabut izin per akun bila perlu, misalnya izin melihat angka keuangan.
4. Simpan. Staf Cabang hanya melihat pesanan dan stok cabangnya sendiri, termasuk saat bertanya ke Asisten Admin.
