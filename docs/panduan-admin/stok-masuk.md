# Mencatat stok masuk

Kata kunci: stok masuk, barang datang, kiriman distributor, tambah stok

Butuh izin: Stok masuk.

1. Buka menu Stok, lalu tekan "Stok masuk".
2. Pilih lokasi tujuan dan isi nomor surat jalan bila ada (boleh dikosongkan).
3. Tambahkan varian dan jumlahnya.
4. Simpan. Semua perubahan tercatat di buku stok varian dengan referensi MSK.
