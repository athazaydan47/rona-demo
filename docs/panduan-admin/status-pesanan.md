# Memproses pesanan

Kata kunci: pesanan, ubah status, proses pesanan, kirim, resi, siap diambil, batal

Butuh izin: Ubah status pesanan (batal butuh izin terpisah).

1. Buka menu Pesanan. Papan kanban mengelompokkan pesanan per status.
2. Buka pesanan, lalu pilih aksi berikutnya: Proses, Kirim (isi kurir dan nomor resi), Siap Diambil, atau Selesai.
3. Pesanan Bayar di Toko ditandai lunas oleh staf cabang saat pembeli datang.
4. Membatalkan pesanan wajib mengisi alasan dan mengembalikan stok yang dipesan.

Asisten Admin tidak pernah membatalkan atau mengubah status pesanan. Ia hanya membantu mencari pesanan dan menunjukkan yang perlu tindakan.
